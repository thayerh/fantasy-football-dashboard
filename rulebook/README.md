# League Constitution

The official rulebook of **Alpha Delta Dynasty** — a 12-team, Superflex, full-PPR dynasty league on Sleeper.

This constitution is the final authority on all league matters. Where this document and the Sleeper platform settings disagree, **this document governs** and the commissioner will correct the platform settings.
